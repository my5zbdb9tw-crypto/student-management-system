# Student Management System

Built with HTML, CSS and JavaScript.

## Features
- Register students with full name, matric number, department, level, email and phone.
- View all registered students and total student count.
- Search student records.
- Update student information.
- Delete student records.
- Save records in browser local storage.

## Files
- `index.html` - page structure
- `style.css` - styling and responsive layout
- `script.js` - registration, search, update, delete and local storage

## How to use
Open `index.html` in a web browser, complete the form and tap Register student. Use the search field to find records. Use Edit or Delete to manage existing records.

Note: This front-end project stores information in the current browser on the device being used. It does not connect to an online database.
